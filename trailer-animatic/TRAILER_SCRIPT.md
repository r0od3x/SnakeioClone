# Snake.io — trailer script

> Personne ne les pilote. Ils chassent, fuient et grandissent tout seuls.

*Generated from `trailer.config.mjs` by `npm run trailer:animatic`: edit the config, not this file.*

## Re-render

Every gameplay shot is cut from a real take of the game, filmed frame by frame at 1080p by the Trailer Studio (`takes/`, shots defined in `trailer/shots.js`); title cards are stills.
Change the timing (`beats`), the text, the sounds or the cut of a shot (`clip`) in `trailer-animatic/trailer.config.mjs`, then:

```sh
npm run trailer:animatic                   # only what changed
npm run trailer:animatic -- --capture      # film the takes again (after editing trailer/shots.js)
npm run trailer:animatic -- --clips        # cut every clip again
```
